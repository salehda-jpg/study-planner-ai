# Study Planner – מתכנן לימודים

פרויקט במסגרת מטלה 2 בקורס AI.

## הבעיה והמטרה
סטודנטים צריכים לעקוב אחר מטלות ובחינות במספר קורסים.
מטרת האתר היא לרכז את המשימות והמועדים במקום אחד ולעזור בניהול הלימודים.

## קישור לאתר
https://mtknn-lymvdym.replit.app/

## יכולות המערכת
- הוספת משימות עם קורס, תיאור, סוג ותאריך יעד.
- עריכת משימות ומחיקה עם בקשת אישור.
- סימון משימות כהושלמו והחזרתן לביצוע.
- הצגת משימות קרובות ומתעכבות בצבעים שונים.
- הצגת מספר המשימות הכולל, הממתינות והמושלמות.
- סינון לפי קורס ומצב השלמה.
- חיפוש בזמן הקלדה לפי שם משימה או קורס וניקוי החיפוש.
- שמירת המשימות בדפדפן באמצעות localStorage.
- ממשק בעברית, מימין לשמאל.

## תהליך העבודה בעזרת AI
1. הגדרת הבעיה, מטרת המוצר והתכונות המבוקשות.
2. ניסוח פרומפט מפורט ובניית האתר באמצעות Replit Agent.
3. בדיקה ידנית של הוספה, עריכה, השלמה וביטול השלמה.
4. בדיקת שמירת המידע לאחר רענון וסימון משימות באיחור.
5. בדיקת סינון והצגת בקשת אישור לפני מחיקה.
6. שיפור המוצר באמצעות פרומפט נוסף להוספת חיפוש.
7. בדיקת חיפוש ללא תוצאות.
8. פרסום האתר והעלאת קוד המקור ל-GitHub.

## החלטות עיצוב
- ממשק בעברית ובכיווניות RTL.
- שימוש בכחול ולבן ופריסה ברורה.
- שימוש בצבעים ובתוויות לציון מצב המשימה.
- הצגת מונים למעקב מהיר אחר התקדמות.

## שימוש באתר
פתחו את הקישור, לחצו על "משימה חדשה" ומלאו את הפרטים.
לאחר השמירה ניתן לערוך, לסמן השלמה, לחפש ולסנן משימות.

## מגבלות
המידע נשמר בדפדפן ובמכשיר שבהם נוצר.
אין סנכרון בין מכשירים או בין כתובות אתר שונות.
מחיקת נתוני האתר בדפדפן עלולה למחוק את המשימות.
